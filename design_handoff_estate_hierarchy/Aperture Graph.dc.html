Read from source

GraphCanvas.tsx draws d3-force circles — pages unlabeled, tech absent, no hierarchy. useScanGraph.ts already emits website / subdomain / page; technologies ride on per-host checks.

Assumption

A force layout cannot carry 36 hosts × 3,090 pages. So the fix is a stated hierarchy — cluster → host → tech → page group — with force kept only where it earns its place.

Answers

Where tech X lives · which host is riskiest · the shape of the estate · where exposed files pool. Every option is judged on those four.
